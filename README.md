# AI Chatbot

An AI-powered chatbot that makes conversations simple, fast, and interactive. This project allows users to ask questions, have natural conversations with an AI model, and receive intelligent responses in real time through a clean and responsive interface.

## Live Demo

**Try it here:**
https://ai-chatbot-eta-sandy-23.vercel.app/

## About the Project

I built this project to explore how modern AI can be integrated into web applications to create a smooth conversational experience. The goal was to develop a chatbot that is easy to use, responsive, and capable of providing helpful AI-generated answers.

The application focuses on simplicity while demonstrating how AI can enhance user interaction in everyday web applications.

## How It Works

1. Enter your question or message.
2. The chatbot sends your request to the AI model.
3. The AI processes your input.
4. The response is displayed instantly in the chat window.

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd ai-chatbot
```

Install the required packages:

```bash
npm install
```

Create a `.env.local` file and add your API key.

```env
API_KEY=your_api_key
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
